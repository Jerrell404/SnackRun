# 🦝 Snack Run

**Snack Run** is a 3D stealth and collection game developed in Unity as part of the COMP307 curriculum at the University of KwaZulu-Natal (UKZN).

Step into the tiny paws of **Bandit**, a mischievous raccoon who sneaks onto a human's property at night to steal snacks without getting caught.

## 🌙 Game Overview

**You're small. The house is not.**

Sneak through the Front Yard, raid the House and escape through the Backyard, avoiding Edgar the homeowner, Whiskers the cat and Rex the dog along the way.

Inspired by *Over the Hedge*, Snack Run blends stealth, exploration and collection in a playful, low-poly night-time world.

## 🧩 Features

- 🦝 Third-person stealth gameplay: sneak, run, jump and hide
- 🍪 A randomised shopping list of snacks to collect
- 🧠 NPCs that see, hear, chase and search for you
- ✨ Custom HLSL shaders, with atmospheric night-time lighting and sound

## 🛠️ Installation & Setup

### 1. Clone the Repository

```
git clone https://github.com/Jerrell404/SnackRun.git
cd SnackRun
```

### 2. Open the Project in Unity

1. Launch Unity Hub.
2. Click **Add project from disk**.
3. Select the cloned `SnackRun` folder.
4. Open it using **Unity 6000.3.21f1** (or another Unity 6 version).

### 3. Play the Game

Open `Assets/Scenes/MainMenu.unity` and press **Play ▶️**.

**Controls:** WASD to move · Mouse to look · R to run · Left Shift to crouch · Space to jump · E to interact or hide

## ⚙️ Blender Requirement

Some characters (Bandit, Rex, Toby and Hammy) were created from first principles in Blender and exported as `.fbx` files. Blender is only needed to view or edit them: [blender.org](https://www.blender.org/download/).

## 💡 Troubleshooting

- Make sure you are using a Unity 6 version.
- Reimport all assets (**Assets → Reimport All**).
- Delete the `Library/` folder and reopen the project to force Unity to rebuild.
